# Скрытые функции (hidden features)

Раздел для будущей базы «скрытых функций» и кодировок по моделям (активация функций, инженерные меню и т.п.).

**Статус в демо:** пусто намеренно. Мы не публикуем пароли инженерных меню и кодировки как факт без проверки на реальном автомобиле.

## Правила наполнения
- Каждая запись обязана иметь поле `verification`:
  - `verified` — проверено мастером «Автомастер 24» на конкретной машине (указать VIN-префикс, версию ПО, дату);
  - `community` — взято из сообщества, **не проверено** (обязательна пометка в интерфейсе «из сообщества, не проверено»).
- Обязательные поля: `brand`, `model`, `years`, `unit` (ГУ/приборка/BCM), `software_version`, `risk` (low/medium/high), `source`, `updated`.
- Записи с риском `high` показываются только в тарифе для СТО.

См. шаблон `_template.json`.
