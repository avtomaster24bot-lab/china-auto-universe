# AutoChina Encyclopedia — демо (MVP)

Энциклопедия и онлайн-диагностика китайских автомобилей для автосервиса **«Автомастер 24»**.
Chery, Geely, Haval, Changan, BYD, Zeekr, Omoda, Exeed, Tank.

Принцип интерфейса: **«разберётся и пятилетний»** — крупные иконки, один экран = одно действие, сначала мобильная версия.

> Это демонстрационная версия. Данные частичные, форма записи никуда не отправляет заявки, оплаты нет.

## Что есть в демо

| Раздел | Адрес | Что делает |
|---|---|---|
| Главная | `#/` | Плитки симптомов («Горит ошибка», «Не заводится», «Стучит», «Не едет», «Русификация»), поиск (код / VIN / слово), выбор марки |
| VIN-декодер | `#/vin/<VIN>` | Разбор по ISO 3779: WMI / VDS / VIS, модельный год по 10-му символу, проверка контрольной цифры, частичная таблица WMI китайских производителей |
| Коды ошибок | `#/dtc`, `#/dtc/P0300` | 33 generic-кода SAE J2012 (P0xxx, U0xxx): описание RU/EN, система, причины по вероятности, шаги диагностики, инструменты |
| Диагностика | `#/obd` | Web Bluetooth → BLE-адаптер ELM327; инициализация AT, Mode 03 (ошибки), Mode 01 (живые данные), Mode 02 (стоп-кадр), Mode 04 (сброс). **Демо-режим** без адаптера |
| Русификация | `#/rus` | 3 уровня: настройки → APK через ADB → прошивка (эксперт), чек-лист, риски |
| Тарифы | `#/pro` | Тизер: Бесплатно / Pro / Для СТО |
| Запись | `#/book` | Форма-заглушка «Записаться в Автомастер 24» |

PWA: `manifest.webmanifest` + service worker (`sw.js`) — сайт ставится на телефон и открывается офлайн (кроме подключения к адаптеру через Bluetooth: оно работает и без интернета, но страницу нужно открыть хотя бы раз онлайн).

## Структура репозитория

```
docs/                 документация (архитектура, формат данных, план)
data/dtc/             база кодов неисправностей (generic.json)
data/vehicles/        марки (brands.json) и WMI-таблица (wmi.json, частичная)
data/symptoms/        симптомы для главной
data/hidden-features/ шаблон базы скрытых функций (пусто намеренно)
web/                  сайт: index.html, css/, js/, icons/, manifest, sw.js
  js/vin.js           VIN-декодер (ISO 3779 / GB 16735)
  js/obd.js           разбор ответов ELM327, формулы SAE J1979, DTC SAE J2012
  js/elm327.js        транспорт Web Bluetooth + демо-адаптер
  js/app.js           интерфейс (SPA на hash-маршрутах, без фреймворков)
tests/                юнит-тесты node:test (VIN, OBD-парсер, демо-адаптер)
tools/                build.mjs, validate-data.mjs, screenshots.mjs (смоук-тест)
.github/workflows/    CI: тесты → сборка → смоук-тест в Chrome → артефакты
```

## Запуск локально

Нужны Node.js 20+ и Python 3 (только для простого статического сервера; подойдёт любой другой).

```bash
npm install          # ставит только playwright-core для смоук-теста (можно пропустить)
npm test             # проверка данных + юнит-тесты
npm run build        # web/ + data/ → dist/
npm run serve        # сборка и сервер на http://localhost:8080/
```

Смоук-тест и скриншоты (нужен установленный Chrome/Chromium):

```bash
npm run serve &      # в отдельном терминале
CHROME_PATH=/usr/bin/google-chrome npm run screenshots   # → screenshots/*.png
```

## Проверка с настоящим адаптером

1. Адаптер ELM327 **с Bluetooth LE** (4.0+). Классический Bluetooth 2.0 и Wi-Fi-адаптеры браузер не видит.
2. Браузер **Chrome или Edge на Android или компьютере**. На iPhone/iPad, в Safari и Firefox Web Bluetooth не работает.
3. Сайт должен открываться по **HTTPS** (или `localhost`).
4. Включите зажигание → «Диагностика адаптером» → «Подключить адаптер».

Сервисы BLE, которые ищет сайт: `FFF0`, `FFE0`, `18F0`, `e7810a71-73ae-499d-8c15-faa9aef0c3f2`. Если ваш адаптер использует другой — добавьте его в `BLE_SERVICES` в `web/js/elm327.js`.

## Публикация

Сайт полностью статический: содержимое `dist/` можно выложить на любой хостинг (Cloudflare Pages, Netlify, Vercel, Яндекс Object Storage, Timeweb, обычный nginx). Обязательно HTTPS — без него не работают Web Bluetooth и service worker.

GitHub Pages не подходит для коммерческого сайта (ограничения правил GitHub), поэтому код хранится в GitHub, а сайт — на отдельном хостинге. Пример деплоя на Cloudflare Pages закомментирован в `.github/workflows/build.yml`.

## Известные ограничения демо

- WMI-таблица частичная (38 кодов, только подтверждённые источником). Расшифровки VDS (двигатель, коробка, комплектация) нет — у каждого завода своя.
- 33 generic-кода. Производительские коды (P1xxx и т. п.) не включены.
- Обычный ELM327 читает только стандартный OBD-II блока двигателя; ABS, подушки, коробка у многих китайских марок требуют специальных протоколов/сканеров.
- Энциклопедия моделей, электросхемы, чертежи коробок, инструкции — пока заглушки «скоро».
- Форма записи и кнопки Pro — заглушки, ничего не отправляют.
- Работа с реальным BLE-адаптером проверена только кодом и тестами парсера на типовых ответах ELM327; на живом автомобиле не проверялась.

## Источники

- ISO 3779 — структура VIN; GB 16735-2019 — китайский стандарт VIN (контрольная цифра обязательна).
- WMI: Wikibooks, «Vehicle Identification Numbers (VIN codes)/World Manufacturer Identifier (WMI)», проверено 18.10.2026. Перед продакшеном — сверка с NHTSA vPIC.
- SAE J1979 / ISO 15031-5 — режимы и PID OBD-II; SAE J2012 / ISO 15031-6 — коды DTC.
- Справочник команд ELM327 (Elm Electronics).
