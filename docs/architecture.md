# Архитектура (демо)

- **Без бэкенда.** Статический SPA на ES-модулях без сборщика и фреймворков. Маршрутизация через `location.hash`, поэтому сайт работает на любом статическом хостинге без настроек rewrite.
- **Данные — JSON** в `data/`, грузятся `fetch` по требованию и кэшируются service worker'ом (сначала сеть, при офлайне кэш).
- **Логика отделена от интерфейса:** `vin.js`, `obd.js`, `elm327.js` не зависят от DOM (кроме Web Bluetooth в `BleElm327`) и покрыты тестами `node:test`.
- **Сборка** (`tools/build.mjs`): копирует `web/` и `data/` в `dist/`, подставляет в `sw.js` список файлов и хэш-версию кэша, создаёт `404.html`.

## Поток OBD

```
Подключить → requestDevice(FFF0/FFE0/18F0/… или имя OBD*/ELM*/Vgate*)
          → поиск характеристик notify + write
          → ATZ, ATE0, ATL0, ATS1, ATH0, ATSP0
          → 0100 (запуск автоопределения протокола) → ATDPN, ATRV
Прочитать ошибки → 0101 (MIL, число кодов) → 03 → parseDtcResponse (CAN / не-CAN, многокадровые)
Живые данные     → 010C, 010D, 0105, 0104 по кругу → формулы SAE J1979
Стоп-кадр        → 0202 (код-причина), 020C00, 020D00, 020500, 020400
Стереть          → 04 (с предупреждением о readiness)
```

`ATH0` (заголовки выключены) добавлен к требуемым ATZ/ATE0/ATL0/ATSP0, чтобы упростить разбор; парсер также понимает ответы с 11-битными заголовками CAN.
